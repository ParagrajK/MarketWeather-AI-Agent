# 🤖 MarketWeather AI Agent — 7-Day Hands-On Series

Build an AI Agent from scratch using **Python + OpenAI Agents SDK**.

The project evolves day by day from a simple Agent into a deployed FastAPI application.

## What You Build

- 🌦️ Live weather capability
- 📈 Stock market capability
- 🔧 Agent tool selection
- 💬 Conversation memory
- 📦 Structured output
- 🛡️ Validation and error handling
- 🌐 FastAPI API
- 🚀 Docker and cloud deployment

## Recommended IDE

**Visual Studio Code (VS Code)** with:

- Python extension
- Pylance extension

## Quick Start

```bash
git clone <your-repository-url>
cd marketweather-ai-agent

python -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```
